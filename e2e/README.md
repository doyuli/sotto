# e2e 冒烟测试

以用户方式驱动**已构建的生产 exe**：合成全局热键、检查窗口、焦点与失焦。
全部通过 Win32 直调（`x/sys`），不依赖窗口标题或截图。

## 运行

```bash
bun run build                                      # 先产出 build/windows-amd64/sotto.exe
CGO_ENABLED=0 go test -tags e2e ./e2e/ -v          # 需要桌面会话（本机跑，CI 无头环境不适用）
```

## 覆盖项

| 测试 | 验证 |
|---|---|
| `TestPanelBubbleFocusAndBlur` | 面板热键唤出输入气泡；气泡**获得焦点**（前台 PID 是 app）；另一个窗口拿走焦点后气泡**消失**——"点击其他地方即走"的回归测试 |
| `TestSnipOverlay` | OCR 热键唤出原生截图遮罩；使用透明 DirectComposition 窗口，不设置全窗淡化；确认 DWM 已解除 cloak、存在 `MyGoSurface` 且没有 WebView 子窗口；显示后 700ms 仍在；20 次打开/取消交替验证 Esc、右键及每屏 HWND 复用 |
| `TestSelectionBubbleShows` | 划词热键无选中文本时回退打开输入面板（划词链路的可达终点） |

热键组合从 app 启动日志的 "hotkeys in force" 行解析后合成发送——默认键位或用户自定组合变了，测试跟着走，不再依赖写死的 Alt+A/S/D。

## 已知测试环境限制

- 热键由 `SendInput` 合成，测试进程先 `AllowSetForegroundWindow` 授予 app 前台权限，模拟真实键盘热键的权益。
- 此冒烟测试只覆盖截图窗口的打开与取消；拖拽/取消输入由 native Tester 覆盖，Windows 实际拖拽到截屏、OCR 的完整链路仍需手工验收。`sotto --ocr <png>` 可单独复核图片识别。

## 原生截图手工验收与测量

纯逻辑和 `ui.NewTester` 覆盖正反向/越界拖选、8 DIPs 临界尺寸、Esc/右键/捕获丢失取消、旧轮次与重复输入、隐藏后恢复、显示器移除和在途抓屏 HWND 的保留。Tester 不替代 Windows 实际合成和多屏验证。

- 单屏与多屏、负坐标副屏，以及 100% / 125% / 150% / 200% 混合缩放：透明输入层覆盖对应显示器，空闲时不画背景/提示文字，拖拽时选区内有淡蓝色半透明底、选区外保持透明；选区边框、DIP 尺寸标注与最终物理截图一致。跨屏内容仍分次框选。
- 快速重复截图、截图中触发输入/划词、切应用、丢失捕获、Alt+F4：取消不提交 OCR，不出现旧轮次幽灵窗口；跨屏焦点切换与启动阶段不误隐藏。
- 框选中断开显示器、改变分辨率/布局或缩放：旧遮罩消失；已提交但尚未完成的抓屏取消且 HWND 在 GDI 返回前保持有效。再次打开使用当前布局。
- 完成框选后，抓屏不含选区着色/边框/尺寸标注，保留 120ms 隐藏等待；真实中文、英文、系统回退和 OCR 的 5 分钟空闲回收均继续工作。
- 浅色/深色桌面检查选区边框与尺寸标签可读性；托盘退出能真正关闭所有原生窗口。

保存前一提交的构建，在同机、同布局下比较“打开截图后取消”，不进入 OCR。记录从快捷键到遮罩可交互的冷/热耗时，以及主进程和 WebView2 子进程组的 Private Bytes、工作集、GPU 内存、句柄与线程数。分别记录打开前、首次取消后和 20 次打开取消后；多屏单独测量。原生窗口隐藏后仍复用并保留 surface/GPU 资源，不把 Hide 视为释放，也不要求 WebView2 进程组退出，因为气泡/设置仍使用 WebView。

## 气泡边缘与长文本手工验收

需在 Windows / WebView2 桌面会话验证：

- 屏幕四角、任务栏上方触发划词和 OCR；气泡应留出边距，右侧空间不足时向左、下方空间不足时向上展开。
- 等待多服务结果依次返回，再折叠/展开卡片；窗口增高或变矮后仍在工作区内，向上展开时底部锚点保持稳定。
- 在副屏打开输入气泡并编辑草稿，失焦隐藏后断开副屏，再按输入热键；草稿内容应保留，气泡回到仍连接的显示器。对可见气泡断开副屏、调整显示布局或缩小分辨率，检查位置与最大高度同步更新；后续结果、卡片折叠不应把窗口拉回旧坐标。
- 使用长原文和多份长译文：原文有高度上限，译文完整展开，卡片内部和页面本身没有额外滚动条；header 下方的内容统一滚动，logo 和关闭/钉住按钮独立固定；滚动条从 header 下方开始，在 header 上滚轮不应滚动内容。
- 鼠标仅悬浮时滚动条不出现；滚轮、触控板、键盘滚动时出现，停止约 900 ms 后淡出。观察显隐前后文字不换行、卡片不抖动。
- 钉住后拖动到另一块较矮的显示器，继续翻译、取消钉住；保留拖动位置，新增内容不超出工作区，滚动条仍能拖动。
- 100%、125%、150% 和 200% 显示缩放、浅色/深色各检查一次；同时验证输入热键复用草稿、失焦隐藏和托盘退出。

## 流式译文手工验收

需在 Windows / WebView2 桌面会话验证（本地 HTTP 模拟与 DOM 测试已覆盖协议和状态，不能替代实机）：

- 同时启用 Bilibili 和已配置的 OpenAI 兼容服务，翻译较长文本；首段译文到达后骨架屏消失，标题显示“生成中”，正文持续补充；新增文字约 150 ms 淡入，旧文字不反复闪动。开启系统“减少动态效果”后新增文字直接显示。
- 生成过程中复制和朗读按钮不可用，英文译文不请求命名格式；成功结束后启用操作并显示完整译文的命名格式。
- 在收到部分文字后断网，检查已有译文保留、出现未完成提示、复制仍不可用；恢复网络后单卡重试，其他卡片与阅读位置保持。
- 使用慢模型或受控模拟接口：保持心跳/推理/译文持续到 30 秒后仍不应被总时限截断；有译文后连续 30 秒无数据应保留文字并提示生成超时。OpenAI“测试连接”成功时显示“连接成功”。
- 用模拟接口返回模型不可用、欠费、限流和超长输入错误，检查测试连接与正式翻译提示一致；流式错误保留已有译文。
- 生成中提交新原文、切换语言、关闭后重新打开；旧流不得覆盖新内容，取消后的卡片不得一直显示“生成中”。
- 生成中滚动、选择文字、折叠卡片；正文节点不被替换、焦点不跳动。浅色/深色和短工作区各检查一次。

## 模型配置手工验收

- 分别修改 OpenAI、硅基流动和智谱模型，重启后配置保留且互不影响；留空恢复默认模型。
- 修改模型后旧测试结果清除；测试期间模型不可编辑，OpenAI 地址同时锁定。
- 模拟设置保存失败：回滚成功时确认连接测试中止但可直接重试；回滚失败时确认需重新修改并保存成功后才能测试。
